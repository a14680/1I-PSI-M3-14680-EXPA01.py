<h1>EXP.A01</h1>

Jogo de Adivinhação - Guess the Number
Este é um simples jogo de adivinhação onde o jogador tenta acertar um número aleatório gerado pelo computador. O jogador tem 6 tentativas para adivinhar o número, e a cada tentativa, o programa informa se o número correto é maior ou menor que o valor inserido.

<h1>Como Jogar<h1>
O jogo gera um número aleatório entre 0 e 20.
O jogador deve adivinhar qual é esse número, inserindo suas tentativas no console.
Após cada tentativa, o programa informa se o número correto é maior ou menor que o valor inserido.
O jogador tem 6 tentativas para acertar o número. Se o jogador acertar antes de esgotar as tentativas, o jogo exibe uma mensagem de vitória.
Se o jogador esgotar todas as tentativas sem acertar, o jogo revela o número correto e oferece a opção de jogar novamente.
